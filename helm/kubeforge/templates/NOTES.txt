KubeForge deployed to namespace: {{ .Values.namespace }}

IMPORTANT: this chart does NOT create the `kubeforge-secrets` Secret. That's
deliberate - it holds the real RDS password fetched live from AWS Secrets
Manager, which is not something a Helm values file should ever hold. Run
this first (or the api/worker pods will sit in CreateContainerConfigError):

  scripts/create-eks-secret.sh

IMPORTANT (Phase 9): api is now an Argo Rollout, not a plain Deployment -
the Argo Rollouts controller must be installed in the cluster BEFORE this
chart is synced, or the `kind: Rollout` resource will fail to apply with an
error about an unrecognized kind. See docs/production-hardening.md.

Check rollout status:

  kubectl get pods -n {{ .Values.namespace }}
  kubectl argo rollouts get rollout api -n {{ .Values.namespace }}
